A real-time geospatial intelligence console for planet Earth

One 3D globe in the browser that brings together public signals: aircraft transponders, vessel AIS broadcasts, satellite orbits, seismographs, fire-monitoring satellites, and public traffic cameras. Controlled with mouse, keyboard, or voice.

Sign in

Access is for registered accounts only. There is no self-registration.

What you can see

Every source is a layer you can turn on and off. The layer panel shows each source's status: live, degraded, or simulated.

  • Aircraft

    Civil flights from OpenSky Network with an adsb.lol fallback, plus military flights from adsb.lol. Click to track, or enter the cockpit view.

  • Vessels

    Vessel positions from AIS broadcasts via AISStream.io.

  • Satellites

    Orbits computed in the browser from CelesTrak TLE data, plus rocket launch context from Launch Library 2.

  • Earthquakes & fires

    Earthquakes from the last 24 hours from USGS and VIIRS satellite fire hotspots from NASA FIRMS.

  • Traffic

    Road geometry from OpenStreetMap. Traffic flow is simulated, or live from TomTom when its key is installed.

  • Public CCTV

    Public traffic cameras (including Austin, Caltrans, TfL London, and cities in Indonesia), with a status label for each source.

  • Infrastructure

    Data centers, dams, submarine cables, and installation context recorded in open maps.

Voice control

A full-duplex voice agent drives the console hands-free: moving the camera, turning layers on, tracking objects, switching visual styles, even drawing annotations right on the globe.

  • The agent only confirms actions that actually succeeded.
  • The microphone is active only after the user turns the voice session on.
  • Voice session audio is sent to the OpenAI service. Sessions are opened through the console server, so the API key never reaches the browser.

Example commands

  • “Fly to Jakarta.”
  • “Turn on the vessel and earthquake layers.”
  • “Track the nearest aircraft.”
  • “Switch to the thermal view.”

Product principles

  • What it models

    Events, assets, infrastructure, and systems: aircraft, vessels, satellites, earthquakes, fires, public cameras, and cities.

  • What it does not do

    Not a people-tracking tool. No search by a person's name and no face recognition.

  • Keys on the server

    Third-party API keys are stored only on the server. Requests to data providers go through the console server and are throttled so free quotas are not exhausted.
